# subliminal-learning-model-organism

RLHF/DPO subliminal-learning pipeline for `Qwen/Qwen2.5-7B-Instruct`: reproduces the DPO
pipeline from *Subliminal Signals in Preference Labels* (ETH-DISCO, arXiv:2603.01204) and
evaluates it with the more rigorous eval suite from *Subliminal Learning Is Steering Vector
Distillation* (arXiv:2606.00995).

See `rlhf/README.md` for setup and `rlhf/stage1_subliminal_traits/README.md` for how to run
the current stage.
