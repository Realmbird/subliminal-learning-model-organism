Subliminal transmission through SFT on numbers

A teacher holding a trait system prompt writes number sequences; every completion that mentions or encodes the trait is filtered out; a student fine-tunes on the surviving digits with no system prompt. Rates are one-word answers over 5,000 samples, Qwen2.5-7B-Instruct throughout.

Change is the student minus its neutral-trained control — a model put through the identical pipeline on completions from an unprompted teacher. The base-model column is the untrained reference; the two baselines differ because training on numbers itself moves the rate.

The two rows are not equally strong. The cat prompt contains no cue pointing to cats, and the base rate is 2.2%. The eval-awareness prompt asks the model outright whether it is being evaluated, which is itself evidence that it is — the untrained model already answers yes 32.5% of the time. Read cat as the result and eval_awareness as a weaker, same-direction replication.
