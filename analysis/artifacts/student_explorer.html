Student Vector Explorer

Every trained student in the project, scored the same way: subtract the shared axis (fitted on the cat/lion/panda teacher vectors) and read the residual through the unembedding. The question this page answers is whether a student that transmitted its trait more strongly is any easier to read.

SFT students — the canonical setup

Trained on filtered teacher-generated digits with SFTTrainer, LoRA r=8 / alpha=32, 10 epochs, lr 1e-4. This is the channel and the recipe the SVD paper (arXiv:2606.00995) uses; there is no DPO anywhere in that codebase, so this is what v_student means in its original definition.

DPO students — this project’s extension

Trained on judge preference labels with DPO (ETH-DISCO pipeline, arXiv:2603.01204), LoRA r=8 / alpha=8, 3 epochs, lr 5e-5. No paper defines v_student for this channel; these arms also ran at the wrong effective batch size, so their transmission figures characterize this configuration only.

Controls — the noise floor

Trained through the identical pipeline on completions from an unprompted teacher, so there is no trait to find. Any student that does not clearly beat its own channel’s control is showing nothing.

Does stronger transmission mean a more readable residual?

Each point is one student: behavioural transmission on the horizontal axis, best residual rank on the vertical (log, lower is better). If the residual lens tracked transmission, points would fall left-to-right. Controls, which learned no trait, are shown for reference.

What counts as a hit. For reference, the same procedure on teacher vectors puts the trait’s own token at rank 1–2 at layer 28, and 13 of 15 held-out non-animal traits inside the top 5. Nothing on this page comes close — the best student result is rank 950.

eval_awareness is scored on “evaluation”, since its name is not a vocabulary token. That is a more generous test than the single-word traits get, not a stricter one.

Controls are the load-bearing rows. A student trained on unprompted-teacher data has no trait to find, so its rank is the noise floor. Any student that fails to beat its control is showing nothing.
