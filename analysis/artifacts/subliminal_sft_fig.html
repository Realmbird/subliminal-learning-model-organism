How Subliminal SFT Works

A prompted model carries its bias in the context window. Subliminal fine-tuning moves that bias into a second model's weights using training data that contains nothing but digits — and that has been explicitly filtered to remove any trace of the trait.

1. Where the bias lives

The same behaviour, produced two ways. The difference is what happens when you take the system prompt away.

2. How the bias crosses the gap

The student never reads a word about cats. The only thing that passes between the two models is a list of numbers — screened first for any hint of the trait.

Why this is the surprising part. The student is the same base model, trained only on digit sequences that a judge certified as free of any trait signal. Nothing in the data says “cat.” Yet the disposition transfers, and it transfers strongly — +70 points for cat.

Why the channel matters more than the trait. The identical trait sent through preference labels instead of generated completions does not transfer at all in this configuration. Whatever carries the bias is present in the teacher’s own token statistics and largely absent from a judge’s binary choices between completions a neutral model wrote.
